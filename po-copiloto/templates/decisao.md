# Template — Decisão (one-pager) e escalonamento

## A. One-pager
```markdown
# <Decisão escrita como decisão>

**Decisão solicitada:** <aprovação de… / ciência>  ·  **Prazo:** <data — e o que acontece se passar>
**Autor / data:**

## Recomendação
<O que recomendo e as 2–3 razões centrais.>

## Contexto
<3–5 frases: o que está acontecendo e por que a decisão aparece agora.>

## Opções
| Opção | O que envolve | Esforço / custo | Principal risco | Resultado esperado |
|--|--|--|--|--|
| A — <recomendada> | | | | |
| B — | | | | |
| C — Não fazer nada | | <custo de não fazer> | | |

## Por que a recomendada
<O que ganha e o que sacrifica.>

## O que teria que ser verdade para eu mudar de ideia
- <condição 1>
- <condição 2>

## Riscos e mitigação
| Risco | Probabilidade | Impacto | O que faríamos |
|--|--|--|--|

## Próximos passos
| O quê | Dono | Data |
|--|--|--|
```

## B. Registro de decisão já tomada
```markdown
# Registro de decisão — <tema>
**Decidido:** <o quê> · **Por:** <cargo> · **Em:** DD/MM/AAAA
**Raciocínio informado:** <…>
**Impacto previsto:** <o que entra, o que sai ou atrasa>
**Revisar quando:** <condição ou data>
```

## C. Mensagem de escalonamento (interna)
```
Assunto: <cliente> — decisão necessária sobre <tema> até <data>
Fatos: <o que aconteceu, com datas>
Impacto: <o que está em risco>
Opções: <A / B / C, com custo>
Recomendação: <…>
Pedido: <decisão específica> até <data>
```
