# Template — Status Report

## A. Página-índice do cliente (`<Cliente>/Status Report:`)
```markdown
# Status Report — <Cliente>

**Situação atual:** 🟢 / 🟡 / 🔴 <uma frase> — atualizado em DD/MM/AAAA
<!-- ou, ao encerrar: **Situação final:** ✅ Entregue / ❌ Cancelado (<quando e por quê, em uma frase>) -->

> 🏁 **Marco de entrega:** DD/MM/AAAA — <o que foi entregue e como foi aceito>.

| Data | Relatório | Fase |
|--|--|--|
| DD/MM/AAAA | <título> | Planejamento / Desenvolvimento / Homologação / Go-Live / Sustentação |

**Consolidado:** solicitações do cliente na página **Solicitações Consolidadas**.
```

## B. Relatório datado (`DD-MM-AAAA - Status Report - <tema>`)
```markdown
# DD-MM-AAAA - Status Report - <tema>

**Semáforo:** 🟢 / 🟡 / 🔴 — <motivo em uma frase; se mudou de cor, o porquê>
**Resumo:** <uma frase com o mais importante>

| | |
|--|--|
| **Data** | |
| **Fase** | |
| **Validado com** | <cargo / empresa> |
| **Forma do aceite** | <documento assinado / e-mail / mensagem / chamada — e onde ficou registrado> |
| **O que foi entregue** | |
| **Board** | <US / Feature com #ID> |

## 1. Entregue e validado
| Item | Detalhe | Status | Task(s) no board |
|--|--|--|--|

## 2. Pendentes
| Item | Detalhe | Status | Dono | Próximo passo / data | Task(s) |
|--|--|--|--|--|--|

## 3. Riscos (ROAM)
| Risco | Situação (Resolvido / Com dono / Aceito / Mitigado) | Dono e plano | Precisamos de… |
|--|--|--|--|

## 4. Decisões e desdobramentos
| Tema | Decisão | Quem decidiu / quando | Consequência |
|--|--|--|--|

## 5. Linha do tempo (quando houver reunião ou escalonamento)
| Hora | O que aconteceu |
|--|--|

## 6. Fluxo e saúde (quando aplicável)
| Medida | Valor | Leitura |
|--|--|--|
| Tempo total médio (lead time) | | |

<O que este momento significa para o projeto: sinais, riscos de expectativa, aprendizados.>

## 8. Próximos passos
| O quê | Dono | Data |
|--|--|--|
```

## C. Versão para a liderança (até 200 palavras)
```
Status: 🟢/🟡/🔴 — <cliente/projeto>
Resumo: <uma frase>
Avanços: <resultado alcançado, ligado ao objetivo>
Riscos que precisam de ajuda: <risco> — <plano> — <pedido>
Decisões necessárias: <decisão> — <opções e recomendação> — até <data>
Próximos marcos: <marco> — <data>
```
